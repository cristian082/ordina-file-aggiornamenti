# Ordina File – aggiornamenti

**Ordina File** è un'app Android di **Cristiano Salidu – Tecnico Digitale – CRISOFT**.

Qui ci sono solo le versioni da installare (APK) e le note su cosa cambia. Non serve aprire
niente a mano: l'app controlla da sola una volta al giorno e avvisa con una notifica quando c'è
una versione nuova (Impostazioni → 🔄 Aggiornamenti).

- `clienti.json` – l'ultima versione approvata.
- `prova.json` – l'ultima versione di prova (solo per chi prova l'app prima dei clienti).

Ogni APK è firmato con la stessa chiave e l'app ne controlla l'impronta (SHA-256) prima di
installarlo.
